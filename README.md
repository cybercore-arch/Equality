# Equality

Быстрый минималистичный клиент для ИИ со своими ключами (BYOK). Сначала Android, потом ПК, код один.

## Как получить приложение на телефон (без Android Studio)

Приложение собирается само на серверах GitHub, тебе нужен только бесплатный аккаунт.

1. Зарегистрируйся на github.com и нажми **New repository** (назови `equality`, можно приватный).
2. На странице репозитория нажми **uploading an existing file** и перетащи **всё содержимое** этой папки
   (включая скрытую папку `.github`; если её не видно, включи показ скрытых файлов). Нажми **Commit changes**.
3. Открой вкладку **Actions**. Сборка стартует сама, занимает около 5–8 минут. Ждёшь зелёную галочку.
4. Открой завершённую сборку, внизу в **Artifacts** скачи **Equality-APK**, внутри будет `app-debug.apk`.
5. Перекинь APK на телефон, открой его. Android попросит разрешить установку из этого источника, разреши.
6. Запусти Equality, нажми ⚙, вставь ключ (инструкция внутри приложения).

Если сборка покраснела, открой её, скопируй текст ошибки и пришли мне.

## Первый запуск

Экран с приветствием: выбери провайдера (Gemini отмечен как самый простой и бесплатный), вставь ключ,
по кнопке «Где взять ключ?» раскроется инструкция, ниже слайдер темы (тёмная / светлая / авто).
Можно пропустить и настроить позже в ⚙.

## Оформление (кнопка 🎨)

Всё применяется мгновенно, пока двигаешь ползунки:
тёмная/светлая тема, цвет акцента, своя картинка-фон (размытие и затемнение), прозрачность сообщений и панелей,
размытие «стекла», скругление, размер текста. Кнопка «Сбросить» возвращает по умолчанию.

## Запуск на компьютере для разработки

```bash
npm install
npm run dev          # http://localhost:5173
npm run typecheck
```

## Стек

React + TypeScript + Vite + Tailwind · @tanstack/react-virtual (виртуальный список) · Zustand ·
Dexie/IndexedDB (локальная база) · Capacitor (Android) · Tauri для ПК (Этап 4).

## Почему не лагает

1. Виртуализация: в DOM только видимые сообщения.
2. Каждое сообщение подписано только на свои данные.
3. Текст стримящегося ответа хранится отдельно от истории.
4. Обновления интерфейса не чаще одного раза за кадр.
5. Markdown разбирается после завершения ответа.
6. История грузится одним запросом по индексу.

## Структура

```
src/
  App.tsx, main.tsx, index.css   — каркас и CSS-переменные темы
  types.ts, modes.ts             — типы и режимы
  db/db.ts                       — база: chats, messages, kv (фон)
  providers/                     — Gemini, OpenRouter/Groq/свой endpoint, SSE
  store/                         — settings (ключи), chat (дерево сообщений), theme (оформление)
  components/                    — ChatView, MessageItem, Composer, Sidebar,
                                   SettingsPanel, AppearancePanel, Background
resources/                       — иконки для Android
.github/workflows/android.yml    — автосборка APK
```

## Схема БД

**chats**: id, title, leafId, createdAt, updatedAt
**messages**: id, chatId, parentId, role, content, createdAt, model
**kv**: key, value (картинка фона)

Сообщения образуют дерево (`parentId`): свайпы — несколько ответов с одним родителем,
ветки — разные продолжения, текущий чат — путь от корня до `leafId`.

## Ограничения сейчас

- Ключи в localStorage (на Этапе 4 заменим на защищённое хранилище).
- APK собирается в debug-режиме: для личного использования подходит, для Google Play нужна подпись.
- Названия моделей по умолчанию могут устареть, правятся в настройках.
- Код не запускался и не собирался в моей среде (нет доступа к установке пакетов), поэтому возможны мелкие ошибки при первой сборке.
