# Equality

Быстрый и минималистичный клиент для ИИ со своими ключами (BYOK). Сейчас для Android. Создан в первую очередь для ролевых игр и длинных чатов, но подходит и для обычного общения и программирования.

**Главное**

- **Свои ключи, никаких аккаунтов.** Gemini, OpenRouter, Groq, DeepSeek и другие провайдеры, плюс любой свой адрес (например, Ollama или LM Studio на твоём компьютере).
- **Не лагает на длинных чатах.** Проверено на чате в 5000 сообщений.
- **Приватность.** У приложения нет сервера, аналитики и отчётов об ошибках. Ключи лежат в защищённом хранилище Android. Подробнее: [PRIVACY.md](PRIVACY.md).
- **Для ролплея.** Персонажи, персоны, лорбуки, импорт карточек, ветки и свайпы ответов, автосжатие контекста.
- **Виджеты.** Телефон с мессенджером, статус, кубики и свои виджеты, которыми управляет модель.
- **Режимы.** Общение, ролплей, программирование и свои режимы с собственным промптом.
- **Поиск в интернете** для любой модели (по желанию, через свой ключ Tavily или Serper).
- **Резервные копии** в файл с шифрованием паролем, экспорт чата в Markdown.
- **Настраиваемый вид.** Тема, цвета, фон, размер текста, скругления.

## Установка

1. Открой раздел **Releases** этого репозитория и скачай `Equality-….apk` из последней версии.
2. Открой файл на телефоне. Android попросит разрешить установку из этого источника, разреши.
3. Запусти Equality, выбери провайдера и вставь ключ. Подсказка «Где взять ключ?» есть внутри приложения.

Обновление ставится поверх прошлой версии, данные сохраняются. Отпечаток сертификата подписи указан в описании каждого релиза: по нему можно проверить, что файл собран автором.

## Статус

Приложение в активной разработке и пока в раннем состоянии: возможны ошибки. Перед важными изменениями делай резервную копию (Настройки → Резервная копия и перенос).

## Как сделано

Приложение разработано автором вместе с ИИ-ассистентом Claude (Anthropic): код пишет ассистент по задачам автора, автор проверяет и тестирует его на своём телефоне. Весь код открыт, читай и проверяй сам. Это особенно важно для программы, которая работает с твоими ключами.
