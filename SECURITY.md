# Безопасность

## Сообщить об уязвимости

Если нашёл уязвимость, не публикуй подробности открыто. Используй раздел **Security → Report a vulnerability** этого репозитория на GitHub (закрытое обращение). Автор отвечает по мере возможности, это личный проект без команды.

## Что защищено и что нет

- Ключи API хранятся зашифрованными в Android Keystore. Это защищает от чтения файлов приложения другими программами, но не от человека с полным доступом к разблокированному телефону или от устройства с root-доступом.
- Приложение блокирует сетевые запросы к чужим адресам и не грузит картинки из ответов модели.
- Если ты указываешь собственный адрес провайдера, ключ уходит именно туда. Проверяй адрес.
- Ключи и сообщения видит провайдер, которого ты выбрал, и только он (плюс сервис поиска, если включён).
- Резервная копия без пароля не шифруется.

## Подпись приложения

Релизные APK подписаны постоянным ключом автора. Отпечаток сертификата SHA-256 указан в описании каждого релиза. Если он не совпадает, не устанавливай файл.
